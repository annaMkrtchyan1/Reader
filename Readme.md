# EPUB Reader App

## 1. Архитектура и технические решения

Приложение построено в соответствии с принципами Clean Architecture, с разделением на слои:

* Presentation (UI) — реализован на Jetpack Compose
* Domain — бизнес-логика и use-cases
* Data — работа с EPUB, локальным хранилищем и источниками данных

Такой подход обеспечивает:

* независимость от UI-фреймворка
* тестируемость
* гибкость при замене реализаций (например, парсера или способа хранения)

Основные технологии:

* Kotlin
* Jetpack Compose
* Room (локальное хранилище)
* epublib

---

## 2. Работа с EPUB

Для обработки EPUB используется библиотека epublib.

### Подход:

* EPUB файл парсится в структурированную модель (главы, ресурсы)
* Контент преобразуется в HTML
* HTML отображается через WebView

### Обоснование:

* WebView позволяет быстро отобразить сложную верстку EPUB
* epublib — легковесная библиотека без привязки к UI

### Расширяемость:

Текущая архитектура допускает переход на:

* полностью нативный рендеринг (без изменения domain слоя)
* кастомный layout engine

---

## 3. Обработка ошибок и нестандартных сценариев

Обрабатываются следующие случаи:

* ошибка чтения EPUB файла
* поврежденный или некорректный EPUB
* отсутствие контента

Подход:

* ошибки пробрасываются из data слоя в UI
* отображаются пользователю через UI-состояния
* реализована индикация загрузки

---

## 4. Производительность

Принятые меры:

* минимизация перерасчета UI за счет Compose state management
* кеширование данных в Room

Потенциальные улучшения:

* предзагрузка следующей главы
* кеширование WebView состояния

## 5. Production-эксплуатация

### Мониторинг:

### Обработка ошибок:

* обработка при сбоях парсинга
* пользователь получает понятные сообщения

### Релизы:

* сборка через Gradle
* поддержка build variants (debug/release)

### Логирование:

* Логирование событий (открытие книги, ошибки загрузки, смена и сохранение позиции чтения)

---

## 6. Риски и ограничения

* WebView:

    * ограниченный контроль над версткой
    * потенциальные проблемы с производительностью на больших книгах

* epublib:

    * ограниченные возможности кастомизации
    * не поддерживает сложные EPUB-фичи на уровне UI

* Room:

    * избыточен для очень простых сценариев, но выбран с запасом на будущее

## 7. Сборка и запуск

### Требования:

* Android Studio (последняя версия)
* Android 7.0+

### Шаги:

1. Клонировать репозиторий
2. Открыть проект в Android Studio
3. Выполнить:

   ```
   ./gradlew assembleDebug
   ```
4. Запустить на устройстве или эмуляторе
